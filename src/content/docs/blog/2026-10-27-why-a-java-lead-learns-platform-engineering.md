For 8 years I've built backend systems that other people deployed and ran. This year I'm learning to run them myself.

As a Java tech lead, I keep noticing that many hard problems sit just past the edge of the code: how it's deployed, observed, secured and recovered.

So I've set myself a 12-month plan, about 10 hours a week:

- AWS the way it's run in production: multi-account, SSO, guard rails, budgets
- Terraform for everything, rebuilt from scratch on a timer
- Kubernetes on my own hardware: an old laptop and two Raspberry Pi 5s
- GitOps, observability, SLOs, and timed restores

One rule: every step ends with evidence — what I built, how I verified it, what broke.

I write the interesting parts here, mostly the failures. The step-by-step versions live under [Runbooks](/runbooks/).
